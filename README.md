# 🚀 SEO Command Center

An autonomous SEO auditing plugin built for the NMG gurugram wooohooooooooooooooo.

## Execution Instructions
1. Boot the live dashboard server:
   `python3 mcp/server.py`
2. Open `http://localhost:7700` in your web browser.
3. Run the pipeline against a Screaming Frog export folder:
   `python3 run.py <path_to_export_folder>`
4. Check the `outputs/` directory for the final `report.json` and `report.html`.
